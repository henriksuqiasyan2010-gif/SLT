# Что нужно делать мне

Всё остальное Claude Code делает сам по файлу `PHASES.md`. Здесь только то, что он сделать не может.

## Как работать с Claude Code

1. Создай пустую папку проекта, положи в неё `PHASES.md` и `MY_TASKS.md`, открой Claude Code в этой папке.
2. Первая команда: «Прочитай PHASES.md и сделай фазу 0».
3. Другие команды:
   - «Сделай фазу N» — начать следующую фазу.
   - «Продолжай» — после того как ты выполнил то, что он попросил.
   - «Проверь обучение» — когда модель обучается на Kaggle.
   - «Исправь: …» — если что-то сломалось или неудобно.
   - «Где мы?» — краткая сводка, что сделано и что дальше.
4. После каждой фазы прочитай его отчёт. Следующую фазу запускаешь только ты.
5. Никогда не вставляй в чат содержимое `kaggle.json` или ключи Azure. Файлы и переменные среды настраиваешь сам.

## До начала (≈ 20 минут)

- [ ] Зарегистрироваться на [Kaggle](https://www.kaggle.com).
- [ ] Подтвердить номер телефона в настройках аккаунта. Без этого Kaggle не даёт GPU.
- [ ] Открыть [соревнование asl-signs](https://www.kaggle.com/competitions/asl-signs), вкладка Rules, принять правила.
- [ ] Settings → API → Create New Token. Скачается `kaggle.json`, положи его в `C:\Users\<твоё имя>\.kaggle\`.
- [ ] Запомнить свой username на Kaggle — Claude Code его спросит.

## Фаза 0 — подготовка (≈ 30 минут)

- [ ] Если попросит — установить нужную версию Python.
- [ ] Проверить `data/vocab.csv`: армянский и русский переводы 250 слов, особенно строки с `?` в колонке notes. Можно отдать команде.
- [ ] Открыть один GIF с анимацией жеста и подтвердить, что это похоже на человека, показывающего жест.

## Фаза 1 — камера (≈ 20 минут)

- [ ] Сесть так, чтобы в кадре были голова, плечи и обе руки, свет спереди.
- [ ] Выучить 3 жеста по анимациям, которые он покажет, и записать каждый по 2 раза его скриптом.

## Фаза 2 — признаки

- [ ] Ничего, только прочитать отчёт.

## Фаза 3 — обучение (ожидание: несколько часов)

- [ ] После того как он отправит обучение на Kaggle, подождать и написать «проверь обучение». Он скажет примерное время.
- [ ] Разрешать или запрещать долгие запуски (больше 3 часов GPU), когда он спросит.

## Фаза 4 — приложение (≈ 30 минут)

- [ ] Выбрать язык интерфейса: армянский, русский или английский.
- [ ] Запустить приложение, показать 10 жестов, написать, что неудобно или не работает.

## Фаза 5 — режим «Строка» (≈ 40 минут)

- [ ] Записать 3 сессии по 5 жестов подряд и для каждой сказать, какие слова там были по порядку.
- [ ] Попробовать режим и написать впечатления.

## Фаза 6 — режим «Обучение»

- [ ] Выучить 5 новых жестов только через этот режим и дать отзыв.
- [ ] Дальше постепенно выучить 20–30 слов для защиты. Список появится в `reports/defense_set.csv`.

## Фаза 7 — озвучка

- [ ] Выбрать источник армянской озвучки:
  - **Записать голосом** — ты или кто-то из команды, около часа на 250 слов. Claude Code сделает программу, которая показывает слово и записывает его.
  - **Azure** — создать аккаунт Azure и ресурс Speech, задать переменные среды. Claude Code даст точные шаги. Для регистрации в Azure обычно просят банковскую карту.
- [ ] Прослушать 20 случайных слов и сказать, если что-то звучит неправильно.
- [ ] Выключить Wi-Fi и проверить, что программа работает без интернета.

## Фаза 8 — сборка и защита

- [ ] Сказать имена участников команды для окна «О программе».
- [ ] Скопировать папку `dist` на другой компьютер с Windows и проверить все три режима.
- [ ] Записать демо-видео на 2–3 минуты (Win + Alt + R записывает окно программы).
- [ ] Скопировать сборку и видео на флешку.
- [ ] Отдать команде папку `reports/team_kit/`.

## День защиты

- [ ] Ноутбук заряжен, зарядка с собой.
- [ ] Свет спереди, однотонный фон, в кадре голова, плечи и руки.
- [ ] Программа запущена заранее, камера проверена.
- [ ] Показывать слова из `reports/defense_set.csv`.
- [ ] Если откажет камера — демо-режим в меню. Если откажет всё — видео с флешки.
